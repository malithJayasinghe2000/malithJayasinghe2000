## About Me

Software Engineer with hands-on experience developing full-stack applications, backend services, and production automation solutions using **Java, Spring Boot, React, Node.js, and AWS**.

Experienced in building REST APIs, microservices, cloud-native applications, and serverless solutions, with practical experience in backend performance optimization and third-party system integrations.

I hold a **BSc (Hons) in Information Technology, specializing in Software Engineering**, from the Sri Lanka Institute of Information Technology (SLIIT).

My technical interests include:

- Backend engineering and scalable application development
- Microservices, distributed systems, and cloud architecture
- LLM integration and Retrieval-Augmented Generation (RAG)
- Intelligent automation and AI-enabled software solutions
- Building reliable, maintainable, and efficient software

Open to collaboration on software engineering, open-source, and product development projects.
